Style Queries: Theme Token on Wrapper

A style container is any ancestor with container-type set. Style queries do not care about its width. They read a custom property set on that container and let descendants react.

Style queries work in Chrome, Edge, and Safari. Firefox support is still pending. Use a supporting browser so the cards change color.
